# Kolczyk Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement in this session.

**Goal:** Change space icons from the sidebar, including automatic favicons and configurable backgrounds.

**Architecture:** One routed personal mod; shared pure model, native picker and cloned sidebar/menu. Bounded local image helper imports assets into the app home.

**Tech Stack:** GPUI JavaScript, PowerShell, Node built-in test runner (development only), vendored Lucide SVG.

**Spec:** `docs/superpowers/specs/2026-11-02-kolczyk-design.md`

## Global Constraints

- No edits to shipped mods, project files or generated declarations.
- Draft changes apply only on Save; Escape/Cancel discard.
- Background settings apply to all icon types.
- No runtime network requests; retain disconnected space preferences.

## Review Focus

- Missing, changed or invalid favicon falls back without breaking sidebar.
- A late async import cannot change the newly selected mode or folder.
- Invalid input cannot be persisted; canceled drafts cannot leak.
- Hidden/collapsed sidebar keeps right-click and attention indicators.
- Installation preserves existing agents/tabs mods and can be undone.
